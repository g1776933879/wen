先连上你的 GitHub

这个应用需要一枚 Token 才能读写你的仓库。拿一次就行，之后不用再填。

  1. 打开 GitHub 网页版，进 Settings
  2. 找到 Developer settings → Personal access tokens
  3. 新建一枚，勾上 repo 权限
  4. 把生成的字符串粘贴到下面「设置」里
